0. 세 가지 원칙
━━━━━━━━━━━━━━━━
하나. 원고 한 장이 모든 것의 원본이다. 카드 문구는 원고의 【카드 데이터】에만 있고, 카드는 그 데이터로 자동으로 찍는다. 카드 문구가 본문과 글자 그대로 같지 않으면 엔진이 카드를 만들지 않는다.
둘. 이미지는 한 길로 간다. 깃허브 저장소(aporia1207/humanity-light-blog-assets)가 주 경로이고, 피클은 원고에 적힌 raw 주소에서 받는다. 드라이브 7_이미지 창고는 사람이 보는 사본이다.
셋. 승인은 한 번이다. 원장이 본부 결재함에서 휴대폰 미리보기 한 장을 보고 승인하면, 그 뒤로는 사람 손 없이 발행까지 간다.

1. 블로그와 독자
━━━━━━━━━━━━━━━━
- 이름: 휴머니티 light (light는 소문자, 영어 표기 예외는 이 한 단어뿐)
- 휴머니티학원이 만든 초등 읽기·쓰기 프로그램 휴머니티 light의 블로그. 12월 개강을 준비 중.
- 독자: 초등 학부모가 중심(90% 이상), 특히 초1~4. 대부분 휴대폰으로 읽는다. 중학교 1학년 쓰기 연계 글은 열 편 중 한 편 안팎.
- 정체성: 책 소개가 아니라 ‘아이가 책에서 질문을 찾는 장면’을 보여 주는 블로그. 핵심 도구는 한 장 틀(큰 질문 하나 · 작은 질문 둘 · 틀릴 수 있는 경우 하나).
- 목소리: 전문가인데 다정한 선생님. 차분한 경어체, ‘~요’와 ‘~습니다’를 섞음. 어려운 말은 바로 뒤에 쉬운 말로 풀기.

2. 카테고리 (셋만)
━━━━━━━━━━━━━━━━
- 책 이야기: 학년별 책, 연재(만화에서 줄글로 등)
- 쓰기 이야기: 한 문장·문단·원고지·독후감·중1 쓰기 연계
- 휴머니티 교육관: 읽기·질문·light 지도 방식, 연구 근거 글
(공지는 필요할 때만. 옛 카테고리 ‘수업 들여다보기·내신 대비 이야기·학부모 고민 상담’은 쓰지 않음)

공개 단계: 1단계 책 이야기(11. 7.~) → 2단계 쓰기 이야기(11. 22. 부스 전주부터 하루 1편) → 3단계 light 지도 방식(11. 23.~ 개강 전). 각 단계 글은 앞 단계 글 한 편으로 이어 준다.

3. 레퍼런스에서 가져온 것과 버린 것 (판 3·4의 근거)
━━━━━━━━━━━━━━━━
가져온 것
- 김종원(공감 60~67, 조사한 곳 가운데 가장 높음): 글 전체를 같은 틀의 카드 여러 장이 끌고 간다. 모든 카드 아래 같은 서명 줄이 붙는다. 첫 카드는 제목을 크게 그대로 쓴다. → 판 4의 서명 줄·표지 규칙.
- 창비 ‘밸런스 게임’: 질문 하나에 두 갈래를 VS로 놓고 고르게 한다. 읽는 사람이 참여한다. 글 끝에 책 정보는 네이버 도서 글감으로 붙인다. → 카드 6 ‘갈림길’, 도서 글감.
- 문학동네 목록 화면: 블로그 첫 화면은 2열 앨범이고 표지가 4분의 1 크기로 줄어든다. 단색 바탕에 큰 글자이거나 큰 사물 하나인 표지만 읽힌다. → 표지 썸네일 검사.
- 올리거: 두세 줄 글 덩어리와 그림이 번갈아 나온다. 글 끝에 같은 주제 글로 이어 준다. → 글자 덩어리 규칙, 연재 지도.
- 책먹보심: 실제 수업 단계를 번호와 색으로 보여 주고, 아이 얼굴은 가린다. 교재는 도서 글감으로 붙인다. → 한 장 틀 번호, 실사 사진 규칙.
버린 것
- 책 속지 사진을 여러 장 찍어 싣는 방식(열정88·올리거): 저작권 부담이 크고, 열정88은 사진이 많아도 공감이 적었다(질문·관점이 없음). 우리는 속지 사진 대신 카드를 쓴다.
- 이모지 소제목, 광고성 문구, 이벤트 말머리.

4. 글은 두 종류
━━━━━━━━━━━━━━━━
가. 짧은 글 (기본) — 700~1,100자, 카드 4장(1·6·3·5)
  연재의 둘째 회부터, 학년별 책 한 권 소개.
  차례: 머리 줄 → [카드 1 표지] → 리드 → 오늘의 질문 → 1. 책 속 한 장면 → 갈림길 문장 → [카드 6 갈림길] → 2. 한 장 틀 → [카드 3] → 3. 집에서 해 보기 → [카드 5] → 맺음 한 줄·다음 글 → 도서 글감 → 상담 안내 → 태그

나. 깊은 글 — 1,800~2,600자, 카드 6장(1·2·6·3·4·5)
  연재 첫 회와 마지막 회, 교육관 글, 쓰기 이야기, 단계마다 대표 글.
  차례: 머리 줄 → [카드 1] → 리드 → 오늘의 질문 → [카드 2 책 정보/근거/원고지] → 1. 책 속 한 장면(또는 근거) → 갈림길 문장 → [카드 6] → 2. 한 장 틀 → [카드 3] → 3. 원장 노트(있을 때만) → 4. 아이의 말로 보기 → [카드 4] → 5. 집에서 해 보기 → [카드 5] → 6. 함께 읽으면 좋은 책(확인된 것만, 0~2권) → 연재 지도 → 출처 → 도서 글감 → 상담 안내 → 태그

글의 리듬 (판 3)
- 휴대폰에서 글자 덩어리는 세 줄(약 90자)까지, 많아야 네 줄. 넘으면 단락을 나눈다.
- 이미지와 이미지 사이 글은 짧은 글 300자, 깊은 글 450자를 넘기지 않는다. 넘으면 소제목 하나를 덜어 내거나 단락을 줄인다.
- 오늘의 질문·갈림길 문장·맺음 한 줄은 가운데 정렬, 설명 단락은 왼쪽 정렬.

공통 규칙
- 머리 줄: “연재명 · 회차 │ 초등 3~4학년 │ n분 읽기” (연재가 아니면 카테고리 이름, 500자 = 1분). 첫 칸은 모든 카드의 서명 줄로도 쓴다.
- 리드: 부모가 실제로 겪는 장면 하나로 시작, 2~3문장. 누군가의 말을 따옴표로 지어내지 않는다.
- 오늘의 질문: 네이버 인용구(따옴표형) 한 줄.
- 갈림길 문장: 책 속 한 장면의 끝에서 “너라면?” 하고 두 갈래를 놓는다. 본문에 질문 한 줄, “가. …”, “나. …” 두 줄로 쓰고 카드 6에 그대로 옮긴다. 정답이 있는 퀴즈나 결말을 드러내는 갈래는 쓰지 않는다.
- 원장 노트: 원장이 실제로 한 말·쓴 글에서만 가져온다(본부 ‘원장 노트 모음’). 없으면 이 칸을 통째로 뺀다.
- 언스플래시 사진: 글마다 한 장, 표지(카드 1) 바탕으로만. 본부가 받아서 눈으로 확인(아이 얼굴·상표·큰 글자 없음)한 뒤 표지를 찍는다. 출처는 출처 칸에 “표지 사진: 작가 이름, Unsplash”.
- 실사 사진 [사진]: 원장이 7_이미지 창고에 올린 수업 자료·책상·손·실물 책 사진만. 깊은 글에 한 장까지. 아이 얼굴·이름·학교가 보이는 사진은 쓰지 않는다(가림 처리도 하지 않고 아예 고르지 않음). 책 속지를 찍은 사진은 쓰지 않는다.
- 연재 회차 사이 서술(몇 단계·몇 번째 책)은 연재 지도표(7번)와 반드시 맞춘다.

6. 카드 — 원고 데이터로 자동 생성
━━━━━━━━━━━━━━━━
번호  자리            서식
1     표지(대표)       C 사진+유리 패널 (사진이 없으면 B 문장 한 줄)
2     정보/근거/본보기  F 도서 목록 카드(책) · E 연구 노트(교육관) · D 원고지(쓰기)
6     갈림길           H 두 갈래 고르기(가 VS 나)
3     한 장 틀         B 문장 한 줄
4     아이의 말        G 말풍선
5     집에서 해 보기    A 손글씨 공책
번호는 자리 이름이고 순서가 아니다. 본문에서는 4번 글 차례대로 1 → (2) → 6 → 3 → (4) → 5 순서로 나온다.
짧은 글은 1·6·3·5, 깊은 글은 1~6 모두.

판 4 공통
- 서명 줄: 모든 카드 맨 아래 가운데 “휴머니티 light │ 머리 줄 첫 칸”(예: 휴머니티 light │ 만화에서 줄글로 · ⑦). 카드만 따로 퍼져도 어디 글인지 알게 한다.
- 표지: 책 제목을 가장 크게, 그 아래 오늘의 질문 한 줄, 위쪽 띠에 연재명·학년. 썸네일 검사: 엔진이 표지 제목 글자 크기를 재어 68px 아래면(앨범 목록에서 17px 아래) 실패로 막는다. 그때는 표지.제목을 줄인다.
- 1080×1080, 학원 엠블럼 작게, 글꼴 나눔손글씨 펜·고운바탕·고운돋움·함렛, 영문 라벨·이모지 없음, 낱말이 두 줄로 쪼개지지 않게(엔진이 글자 크기 자동 조정).
- 파일 이름: <글 코드>_<번호>_<이름>.png (표지는 .jpg). 이미 발행된 글의 카드를 다시 찍으면 이름 끝에 _v2.

10. 원고 문서 형식 (이 형식만)
━━━━━━━━━━━━━━━━
【작업 구분】 새 글 / 기존 글 수정(기존 제목·주소)
【글 코드】 예: c07 (영문 소문자+숫자, 파일 이름에 씀)
【글 종류】 짧은 글 / 깊은 글
【카테고리】 책 이야기 / 쓰기 이야기 / 휴머니티 교육관
【머리 줄】
【제목】
【본문】 [카드 n]·[사진] 자리 표시 포함
【태그】
【카드 데이터】 한 줄에 하나씩 “키: 값”. 값은 본문에 나오는 문장을 그대로 복사한다.
  표지.칩1(학년) / 표지.칩2(연재명 회차) / 표지.제목(책 제목) / 표지.한줄(오늘의 질문) / 표지.사진(직접 주소 또는 7_이미지 창고 파일 이름, 없으면 비움)

  (교육관) 근거1.숫자 / 근거1.대상 / 근거1.결과 / 근거2.숫자 / 근거2.대상 / 근거2.결과
  (쓰기) 원고지.예문
  갈림길.질문 / 갈림길.가 / 갈림길.나 (가·나는 26자 이하)
  한장틀.띠 / 한장틀.큰질문 / 한장틀.작은질문1 / 한장틀.작은질문2 / 한장틀.틀릴수있는경우
  아이말.질문 / 아이말.대답1 / 아이말.대답2
  집에서.질문1 / 집에서.질문2 / 집에서.질문3 / 집에서.맺음

11. 흐름 (한 번 승인)
━━━━━━━━━━━━━━━━
본부(순찰)
 1) 원고를 쓰고 독립 검수관이 판정표로 검사
 2) 카드 엔진: python3 tools/cards/engine.py <원고> --out cards --preview <미리보기 파일>
    일치 검사·썸네일 검사를 통과해야 다음으로(실패하면 원고를 고쳐 다시. 검사를 끄거나 우회하지 않음)
 3) 카드를 깃허브 저장소 cards/<글 코드>/에 올리고 raw 주소를 【이미지】에 적음. 미리보기(원고 전문이 들어감)는 저장소에 올리지 않고 드라이브 1-0_결재 대기에 원고와 함께 둔다.
 4) 본부 결재함에 1건: 휴대폰 미리보기 한 장 + 확인 필요 요약
원장
 5) 본부 결재함에서 승인 / 수정 지시 / 반려 — 이것이 유일한 승인
본부(순찰, 다음 회차)
 6) 승인 → 원고를 1_발행 대기로. 수정 지시 → 고쳐서 다시 결재. 반려 → 4_원본 보관.
피클
 7) 1_발행 대기의 원고만, 공개 순서표의 날짜대로 발행(다시 묻지 않음). 처음 3편은 발행 직후 원장이 휴대폰으로 한 번 확인한다(시험 기간).
 8) 발행 뒤 글 주소를 원고 문서 맨 위에 적고 2_발행 완료로 옮김. 형식 점검(빈 줄·카드 자리·인용구·정렬·글감·태그)에서 걸린 것은 고치지 말고 본부에 알림.
예외: 비공개 기간(11. 6.까지)과 기존 글 교체는 5) 없이 6)으로 바로 감(원장 지시 11. 4.).

12. 피클이 하지 않는 것
━━━━━━━━━━━━━━━━
